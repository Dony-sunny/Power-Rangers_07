# Role workspace coverage

All roles share the same database. WORKING means an executable prototype action using synthetic inputs; PARTIAL identifies a working subset; ROADMAP identifies production extensions. The exact individual features from all fifteen master role lists are preserved in [Feature audit](FEATURE_AUDIT.md).

| Role | WORKING | PARTIAL / ROADMAP |
|---|---|---|
| Shipper procurement | Manual/text/document/scanned PDF/image intake, XLSX/CSV preview/template/error report and atomic valid-only import; quote/rate benchmark, full modes/SLA/carbon, matching profiles, individual/pool/scheduled/recurring approvals, capacity contracts and shipment history | Preferred-operator preference management, negotiated legal contracts and real rate feeds; external AI not credential-tested |
| Shipper dispatch | Shipment milestones/ETA, replacement/later/terminal/service/road alternatives, whole-pool recovery, truck appointment/assignment, handover/photo evidence and documents | Live map GPS, automatic lateness alerts and carrier feeds; recovery pre-departure only |
| Warehouse | Assigned loads, packing, weight/volume guards, handover, loading sequence, gate-out, damage photos, authorized QR/print labels and loading sheet | Detailed equipment checklist, physical gate scanning and long-term inventory |
| Consignee | Incoming cargo/ETA, quantity/name/discrepancy records, photo evidence, delivery documents, secure local challenge/verification | OTP enforced after challenge request; old milestone-only deliveries are unverified. Planned unloading-window card and production SMS/legal signature remain partial |
| Vessel operator | Profiles/capacity/availability, compatible demand, pool and return projections/revenue, scheduled patterns/participation, synthetic reliability/on-time/cancellation/claims, own payment/settlement visibility and navigation reports/photos | Quote negotiation, dedicated rate-benchmark/heatmap screen and real provider evaluation |
| Fleet dispatcher | Profiles/register/listing, operating states/conflicts, crew records, fleet assignment preview with objectives/reposition estimates, recurring patterns and reports | Booking approval stays with authorized commercial/control roles; full multi-tour VRP, dedicated all-vessel map and push alerts |
| Captain | Responsive assigned voyages, manifests, approved route/restrictions/constraints, ETA/instructions, milestone confirmations, incident photos/text reports, simulated progress and labeled offline read cache | Live GPS ingestion, official weather/notices and disconnected writes |
| Terminal operator | Resource/calendar/queue, collision checks and alternate slots, equipment/storage handling capacity, truck appointments, handling completion/delay record, charges and status | Full gate lifecycle, labor rostering and long-term storage occupancy; fixed prototype handling duration |
| 3PL control tower | Cross-tenant planning/intake/bulk management, pooling, recurring capacity, fleet optimization approval, terminal resources, active/delivered/intervention board and recovery | Dedicated cost trends, automatic lateness monitors, contract-specific SLA penalties and scorecard comparison |
| Finance | Itemized accepted-rate/first-mile/terminal/water/wait/last-mile invoices, payment/dispute/resolution states, history, delivery-gated settlement and prototype invoice | Real funds, escrow, tax and insurance connections |
| Compliance | Certificate/expiry review and demo verification, dangerous-goods/category/maintenance booking gates, PASS/FAIL reasons and audit | Legal identity/document authenticity and separately signed pre-voyage checklist |
| Maintenance | Defect, downtime/booking block, inspection/due date and return-to-service | Predictive maintenance and IoT feeds |
| Waterway control | Network/depth/restrictions/terminal status, failure intelligence, report photo/review/dispute/explicit promotion and expiry | Live lock/traffic/official notice feeds, voice reporting and push navigation alerts |
| Government | Same-booking selected/completed impact, utilization/backhaul, demand/gaps/activation, corridor reliability, failed-demand reasons and historical modal-shift upload | Verified real operational histories, audited public reporting and authoritative infrastructure planning |
| Admin/trust | Organizations/users/roles/membership, disable/access revocation, audit, diagnostics/connectors, evidence, payment/dispute workspace, seed/reset/A–F and clean guided judge story | Production identity provisioning/SSO and official verification; public publishing requires approval |

Implementation modules: [Workspaces](../frontend/src/components/Workspaces.tsx), [advanced scheduling/fleet](../frontend/src/components/Advanced.tsx), [operations](../frontend/src/components/OperationalTasks.tsx), [evidence](../frontend/src/components/Evidence.tsx), [administration](../frontend/src/components/Administration.tsx), [network intelligence](../frontend/src/components/NetworkIntelligence.tsx). Backend authorization remains authoritative; hiding a button does not grant permission.
