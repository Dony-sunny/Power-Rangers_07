# Deterministic planning and reviewed extraction

Deterministic code owns feasibility, schedules, whole-truck calculations, shared resource allocation, integer money and acceptance checks. AI/document/voice extraction produces proposed cargo fields for review. It cannot override constraints, approve a quote or invent a measurement.

The current marketplace uses Cargo Lines: load-unit-aware trip costs, fixed sailing and handling terms, per-consignment accepted quote snapshots, resource jobs, shared milestones and individual receipts. The original matching, pooling, backhaul and recurring capacity tools are exposed under Team tools. Their outputs remain previews or explicitly labeled prototype workflows; an optimization result does not guarantee revenue or real provider supply.

The optional model/STT adapters retain local fallback. No credential-tested native IBM/watsonx connection is established by this restoration. Public corridor weather is independent read-only context and does not feed dispatch or hard feasibility.
